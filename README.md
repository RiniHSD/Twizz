# Tuizz - Aplikasi Web Kuis

Aplikasi web ini dibuat untuk membuat dan mengelola kuis interaktif, khususnya untuk PT Titian Maju Bersama. Aplikasi ini memungkinkan pengguna untuk membuat, meng-host, dan berpartisipasi dalam kuis secara real-time.

## Akses Aplikasi

Aplikasi dapat diakses melalui: [tuizz-97ce4.web.app/](https://tuizz-97ce4.web.app/)

## Fitur Utama

- Pembuatan kuis dengan mudah
- Mode host untuk mengelola kuis
- Mode partisipan untuk mengikuti kuis
- Leaderboard untuk melihat peringkat
- Integrasi dengan Firebase untuk penyimpanan data

## Teknologi yang Digunakan

- **Frontend**: React dengan Vite
- **Backend**: Firebase (Authentication, Firestore, Hosting)
- **Styling**: CSS

## Cara Menjalankan Lokal

1. Clone repository ini:
   ```
   git clone https://github.com/RiniHSD/Twizz.git
   cd Twizz
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Jalankan development server:
   ```
   npm run dev
   ```

4. Buka browser dan akses `http://localhost:5173`

## Build untuk Production

```
npm run build
```

## Deploy

Aplikasi ini di-deploy menggunakan Firebase Hosting.

Untuk informasi lebih lanjut, hubungi pengembang.
